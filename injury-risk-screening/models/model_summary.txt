1. MODEL BUNDLE FILE
   Source Path: models/pose_landmarker_full.task
   File Format: Google MediaPipe Task Bundle (ZIP container holding TFLite neural network graphs)

2. EXTRACTED TFLITE NEURAL NETWORK GRAPHS
   a) pose_detector.tflite
      - Purpose: Bounding-box detection of human body candidates in RGB frames.
      - Input Tensor: 1 x 224 x 224 x 3 (Normalized RGB image)
      - Output Tensors: Bounding box coordinates (xmin, ymin, width, height) + Keypoint score predictions.

   b) pose_landmarks_detector.tflite
      - Purpose: 3D Human Pose Landmark regression model (BlazePose GHUM 3D architecture).
      - Input Tensor: 1 x 256 x 256 x 3 (Cropped RGB torso/person tensor)
      - Output Tensors:
        * Tensor 0: 33 3D Joint Landmarks (x, y, z normalized image coordinates) + visibility scores
        * Tensor 1: 33 3D World Landmarks (x_world, y_world, z_world metric coordinates in meters)
        * Tensor 2: Pose presence confidence score (0.0 to 1.0)
        * Tensor 3: Segmented body mask heatmap
